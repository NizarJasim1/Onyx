# ONYX — كتالوج القدرات الكامل (اعرف أداتك بالكامل)

> هذا المستند مبني على قراءة الكود الفعلي (`authpath/`, `external_targets/`) لا على التسويق.
> كل قدرة مذكورة موجودة فعلاً في الكود ومُتحقَّق منها.

---

## 1) القاعدة الحاكمة (لماذا صفر إيجابيات كاذبة)

| الرمز | المبدأ | أين يعيش |
|---|---|---|
| **RL1** | لا استقراء/تعلّم — كل حكم من قانون معرّف أو حقيقة مقيسة | `eil.py`, `provenance.py` |
| **RL2** | لا نموذج ML/LLM في مسار القرار — المسار الحار: parse + جدول + predicate | `engine.py` |
| **RL3** | التأكيد بـΔstate فقط — لا اكتشاف بدون تغيّر حالة مقروء | `confirmer.py` |
| **RL4** | كل نتيجة قابلة للتقرير — مسار سببي + PoC + قانون مُنتهَك | `poc.py` |
| **RL5** | Scope-Guard — أي شك = لا تفعل شيء (dry-run افتراضي) | `scope_guard.py` |

**الخلاصة:** أي خطأ تصنيف يسبب *تدقيقاً أكثر* (إسقاط مرشّح)، لا نتيجة ملفّقة أو مفقودة.

## 2) محرك الكشف — 17 صنف تأثير (هذي قوّتها الحقيقية، أغلبها ما تستخدمه)

كل صنف = قانون "صحيح بالتعريف" يصدر **مرشّح**، ثم الـconfirmer يثبته بـΔstate:

| الصنف (EffectClass) | القانون | OWASP API | تحدي crAPI المقابل |
|---|---|---|---|
| **OBJECT_ACCESS** | الكائن ∈ نطاق المالك | API1 BOLA | سيارة/طلب/تقرير غيرك |
| **FIELD_PROJECTION** | لا حقل خاص يُسرَّب | API3 | تسريب بيانات (feed/video) |
| **OWNERSHIP** | الحقل المميّز خادمي-موثوق | API3 BOPLA | mass-assignment (role/price) |
| **AUTHORITY** | فعل ⊆ صلاحية المبدأ | API5 BFLA | حذف/تعديل مورد غيرك |
| **AUTHORITY_GRANT** | حفظ صلاحية المنح | API5 | ترقية صلاحية |
| **PAYMENT** | المدفوع ≥ المستحق | API6 | تلاعب دفع |
| **PRICE** | الإجمالي = مجموع البنود | API6 | تلاعب سعر |
| **STATE_GATE** | الحالة النهائية تحتاج سابقتها | API6 | تخطّي حالة/استرجاع |
| **INVENTORY** | 0 ≤ كمية ≤ المتاح | API6 | تلاعب مخزون |
| **COUPON** | الاستخدامات ≤ الحد | API6 | إعادة كوبون |
| **TEMPORAL_DRIFT** | credential صالح بعد إلغائه | — | صلاحية قديمة (صنف رائد) |
| **AUTH_REGRESSION** | حقل حُجب@T1 ثم ظهر@T2 بلا تغيّر دور | — | انحدار تفويض |
| **CROSS_SURFACE** | الباب غير القانوني ⊆ القانوني | — | تباعد المسارات |
| **STRUCTURAL_DIVERGENCE** | الرد يطابق قواعد صلاحية أعلى | — | تباعد بنيوي |
| **EMERGENT_BREAK** | ابن مقروء والأب المعلن ممنوع | — | كسر مركّب متعدد الخطوات |

> **ميزة قد لا تعرفها:** الأصناف الخمسة الأخيرة (temporal/regression/cross-surface/structural/emergent)
> نادرة جداً في أدوات السوق — أغلب الأدوات تكشف BOLA فقط. أداتك تكشف كسور **زمنية وبنيوية ومركّبة**.

## 3) محاور القياس (لماذا النسب حقيقة لا تخمين)

- **Axis 1 — Provenance** (`provenance.py`): كل قيمة موسومة بالمبدأ الذي حملها أول مرة، مقسومة إلى
  شرعي (مرحلة المراقبة) مقابل هجوم — إثبات ملكية مقاوم للغسل ومستقل عن الترتيب.
- **Axis 2 — Envelope** (`envelope.py`): ما **حازه** كل مبدأ (HELD) مقابل ما **رآه** (SEEN).
- **Conservation RL19** (`conservation.py`): الصلاحية كمية **مصونة**؛ المُمارَس ⊆ المصون عند إحداثي
  (كائن × خاصية × دالة × خدمة × زمن). هذا يمسك تسريب القراءة الذي لا يصله مؤكِّد الكتابة.

## 4) الترسانة — نقاط الدخول (كل واحدة محرك مستقل)

| المحرك | ماذا يفعل | متى تستخدمه |
|---|---|---|
| `hunt_crapi.py` | متخصص crAPI: يسجّل/يكتشف/يهاجم/يقرّر | اختبار crAPI مباشرة |
| **`onyx_recon.py`** | **محرك عام N-مبادئ على أي OpenAPI/HAR** | أي هدف مصرّح (الأقوى للعموم) |
| **`conductor.py`** | HAR/OpenAPI → حزمة تشريح: مؤكَّدات + فرضيات مرتّبة | تحليل شامل بضغطة |
| `breaker.py` | Layer-3: BOLA علاقات/سلاسل + state-gate | كسور متعددة الخطوات |
| `alt_paths.py` / `alt_paths_deep.py` | تعلّم من الرفض + سلاسل pivot و authz-key | أبواب بديلة مخفية |
| `graphql_surface.py` | قراءة عقد GraphQL عبر المالكين | واجهات GraphQL |
| `sequences.py` | تدفقات متعددة الخطوات (flows JSON) | منطق أعمال معقّد |
| `token_probes.py` | JWT alg=none / tenant — يؤكَّد بـΔstate فقط | فحص توكن (بصدق) |
| `live_hunt.py` | نسخة turnkey → تقارير جاهزة للتقديم | صيد مصرّح فعلي |
| `agent_loop.py` | **المحلل في الحلقة**: المحلل يقترح، المحرك يثبت/يرفض | أتمتة ذكية آمنة |
| `dossier.py` / `sitemodel.py` / `invariants.py` | تشريح HAR/OpenAPI (كائنات/علاقات/ثوابت) | فهم السطح |
| `python -m authpath serve` | **لوحة تحكم حيّة** (HUD) تعرض المسار مرحلة-مرحلة | عرض/تقديم |
| `python -m authpath scan spec.json` | المحرك الأساسي من ملف spec | تكامل مخصّص |
| `python -m authpath import-har` | HAR → spec | من التقاط بروكسي |

> **ميزات مخفية مهمة:** `conductor` يفصل **المؤكَّد** عن **الفرضيات** (لتحكم أنت)، و`agent_loop`
> يعطي المحلل "مقبس آمن" لا يستطيع تجاوز البوابة أو اختراع نتيجة، و`serve` لوحة عرض حيّة للمحكّمين.

## 5) قدرات المتانة والنزاهة (نادرة في السوق)

- **Chaos Anvil** (`proving_world/anvil.py`): يحقن فوضى إنتاج (stale reads, cache bleed, retries,
  429) أقسى من الواقع؛ الـprecision تبقى 1.000 — لا منافس ينشر رقم صفر-FP تحت فوضى.
- **Evidence Tiers T1–T4** (`evidence.py`, RL20): كل رقم يحمل رتبته (مستقل/ذاتي/تقدير/بالبناء)،
  مشتقة من مصدر الهدف لا مُختارة — الأداة تطبّق "أثبِت لا تدّعِ" على نفسها.
- **Proof-Carrying Measurement (PCM)**: كل قياس مختوم بسلسلة hash؛ طرف ثالث يعيد اشتقاق كل نتيجة
  بإعادة تشغيل النسخة الخام — لا يمكن تزوير أو تضخيم النتائج.
- **Certifying algorithm** (`certificate.py`): شهادة قابلة للتحقق لكل حكم.
- **Anti-circularity**: `world.py` لا يستورد أي كود كاشف (AST guard)، والثغرات مختومة hash قبل الهجوم.

## 6) خارج النطاق (بصدق — استخدم أداة مكمّلة)

حقن (SQLi/NoSQLi/XSS) · SSRF · تشفير JWT (alg-none يُفحَص لكن يؤكَّد بـΔstate فقط) ·
brute-force / rate-limit · أي شيء ليس قرار تفويض. **الضيق مصدر الدقة، لا ثغرة فيها.**
