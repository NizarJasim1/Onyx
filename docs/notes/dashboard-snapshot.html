01 / the idea

Everyone else guesses. ONYX checks the state.

The #1 API vulnerability is the hardest for automated tools because it depends on the app's own authorization model. The field copes with heuristics: did the response differ? is it not a 403? Those break both ways — a cached response cries wolf, a silent leak slips through.

Autorize
Response comparison — status / length / body fingerprints FP/FN possible
Akto
Swap the auth token or change the method, replay, match the response template
StackHawk
Multi-user crawl — flags when it returns data “instead of 403 Forbidden” status-based
Escape · Snyk
AI/LLM generates payloads and classifies ownership probabilistic
ONYX
Confirms only on a proven Δstate — write-then-read-back, cross-principal effect, foreign object gone. No ML in the decision path. deterministic
02 / the edge

Why a state check is sound where a status check isn't

RL23
Mass-assignment. Flip an order to returned and get refunded. The write's response is just {ok} — nothing to compare. ONYX reads the state back and proves the mutation persisted.
RL25
Admin-delete BFLA. A delete returns {deleted} with no owner. Confirming on “not a 403” is a status inference. ONYX proves the owner's object is now gone on the owner's own re-read.
RL22
Field-level leak. A feed exposes another user's email with no foreign id in the request. ID-swapping never triggers; ONYX flags the private field by provenance.
RL24
The false alarm nobody else survives. A shared cache serving A's body to B looks exactly like a cross-user leak. ONYX re-checks on a cache-busted, quorum-voted re-read and abstains when it won't reproduce.
03 / the guarantee

Five red lines, never crossed

RL1 · no induction
No ML, no pattern-learning anywhere.
RL2 · no LLM
Nothing probabilistic in the decision path.
RL3 · Δstate only
A status or length diff is never proof.
RL4 · reportable PoC
Every finding ships a replayable proof.
RL5 · fail to silence
When unsure, abstain — never guess.

Recall is ~0.94 clean, ~0.80 under heavy chaos — deliberately not 1.0. The sacred rule is zero false positives; when an observation won't stabilise, ONYX stays silent. A tool that never cries wolf is worth more than one that finds a few more and burns your trust.
