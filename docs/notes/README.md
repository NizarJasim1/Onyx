# Research notes

Working notes written while each layer was designed and hardened: the original v3
design spec, deficiency analyses and how each was closed, scale tests on large
emulated targets, and adversarial hardening reports.

They are kept for anyone who wants the reasoning behind a module. For the current
picture, start with [../architecture.md](../architecture.md) and [../status.md](../status.md).
Numbers in these notes are self-measured (`T2`) unless a note says otherwise.
